# Flip Clock App

A beautiful flip clock application built with React, Vite, TailwindCSS, and shadcn/ui.

## Features

- ⏰ **Real-time Clock** - Beautiful flip animation showing current time
- ⏱️ **Countdown Timer** - Set custom countdown timers
- 🖥️ **Fullscreen Mode** - Immersive fullscreen experience
- ⚙️ **Options** - Customize clock settings (24-hour format, show seconds, theme)
- 📱 **Responsive Design** - Works on all screen sizes
- 🎨 **Modern UI** - Built with shadcn/ui components

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Usage

1. **Clock Mode** - Default mode showing current time with flip animations
2. **Countdown Mode** - Click "Countdown" to set a custom timer
3. **Fullscreen** - Click "Fullscreen" to enter fullscreen mode (press ESC to exit)
4. **Options** - Configure display preferences
5. **About** - View app information
